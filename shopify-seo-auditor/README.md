## The clearest difference: accuracy

The baseline audit contains several confident findings that conflict with the deeper live checks performed by the Skill.

### 1. Hreflang

**Without the Skill**

> “No hreflang tags, despite 200+ locale URLs existing.”

**With the Skill**

The Skill found that hreflang tags do exist for the active locale set. The real problem is more specific:

- `fr-BE` is declared as a reciprocal hreflang target;
- the target page is `noindex, nofollow`;
- around 180 additional Shopify Markets locale folders appear in the sitemap even though they are non-indexable.

This changes the recommendation from “enable hreflang” to “repair the market configuration and remove invalid sitemap entries.”

### 2. Product canonical

**Without the Skill**

> “Missing canonical tag on product pages.”

**With the Skill**

The live sample found the site's core canonical setup to be healthy. The canonical issue was therefore not retained as a finding.

### 3. Product structured data

**Without the Skill**

> “The Product schema is missing offers and aggregateRating.”

**With the Skill**

The Skill found `ProductGroup` and `Offer` data already present. The actual missing element was the review rating markup:

- Yotpo reviews are present on the page;
- `aggregateRating` is absent from the JSON-LD;
- the recommended fix is to enable Yotpo's native structured-data output and validate it with Google's Rich Results Test.

## Issues found only through the Skill workflow

The Skill surfaced several high-value findings absent from the baseline:

1. Two competing indexable “all products” collections:
   - `/collections/all`
   - `/collections/tous-les-produits`

2. A broken `fr-BE` hreflang/indexation relationship.

3. Roughly 180 non-indexable Shopify Markets folders included in XML sitemaps.

4. Old seasonal collections that remain indexed.

5. Three empty blog indexes that remain indexable.

6. Missing `aggregateRating` markup despite live Yotpo reviews.

## From observations to implementation

The Skill does not stop at identifying problems. Each recommendation includes:

- the affected SEO area;
- evidence from a live URL;
- the expected SEO impact;
- a Shopify-specific implementation method;
- an owner such as Dev, Dev/Ops or Content;
- a validation condition after deployment.

### Example

**Finding**

Two indexable “all products” collections split internal links and commercial relevance.

**Implementation**

- Keep `/collections/tous-les-produits`;
- remove links to `/collections/all`;
- create a Shopify URL redirect;
- confirm that the old URL returns a `301`;
- confirm that only one version remains indexable.

## Ranked output generated by the Skill

The audit delivers:

- 6 documented SEO issues;
- 5 technical recommendations;
- 4 content recommendations;
- an impact/effort matrix;
- an 8-item ranked shortlist;
- a deployment and validation checklist.

## Conclusion

The main benefit is not a longer answer.

The Shopify SEO Auditor Skill produces a more reliable audit by:

- reducing material false positives;
- identifying the actual Shopify-specific cause;
- supporting findings with verifiable evidence;
- converting recommendations into deployable tasks.

> **Without the Skill:** plausible SEO advice, but several incorrect diagnoses.  
> **With the Skill:** a verified Shopify SEO remediation plan.
